Free and open source

A real terminal, on your PS5.

PS5Term runs on the console's own screen: a native shell for the PS5's files, a real Linux shell with curl, nano, tmux and htop, and SSH and SFTP from your computer. Use a keyboard, a mouse or just the controller.

Download Get started

In ProsperoStore, or download it here. For a jailbroken PS5 with a homebrew launcher.

  • 2 shells: native and Linux
  • 3 ways to drive it: keyboard, mouse, controller
  • 1 SSH and SFTP server built in
  • 0 cost: free and open source

What it does

Your console, with a command line

Everything runs inside the app. No payload to send, no separate SSH server and no computer needed to use it.

A real Linux shell

  • RISC-V Linux 6.12 with BusyBox, curl with HTTPS, nano, tmux, htop, jq and less.
  • Files in /mnt/data stay between starts; add Alpine or Ubuntu 24.04 with their apk or apt packages.
  • The PS5's own files are at /mnt/ps5. Internet goes out through the app; nothing can connect in.
🗂️Native shellls, cat, cp, grep, sha256sum, ps, sysinfo and more, on the PS5's own files.
▶️PS5 programsrun starts a PS5 ELF program in the tab, ncurses menus included, through your ELF loader.
🔐SSH and SFTPLog in from your computer with a password or your own key.
🗔Tabs and split panesUp to four sessions, side by side if you like.
🔎Search and copyFind text in the output, select it and paste it back.
🎨Colour and UnicodeFull colour, box drawing and accented text at native 1080p.
🌍In your languageThe app speaks all 21 languages of this site and follows your PS5's language. Linux stays as a normal Linux would be.
🎮Any input, aloneKeyboard, mouse or controller: every action works with each.

Guide

Get started in three steps

  1. 1

    Install from ProsperoStore

    Open ProsperoStore on your PS5, find PS5Term under Utilities and install it. Updates arrive there too. Or download the ZIP below and copy its FAKE99260 folder to /data/homebrew/FAKE99260, for example with PS5Upload.

    Download

  2. 2

    Open PS5Term

    Launch it from your homebrew launcher. The built-in shell is ready; type help.

  3. 3

    Turn on what you need

    Open Settings (Options on the controller) to start Linux or switch on SSH. Settings shows the password and the exact command to connect.

From your computer

SSH and SFTP on port 2222

Both logins use the password shown in Settings, or your own public key. Replace the address with your console's.

A Linux shell

Starts Linux if it isn't running. Works with full-screen programs and terminal apps such as Ghostty and Warp.

ssh -p 2222 linux@192.168.1.50

The native shell

The PS5's own files and system commands.

command ssh -T -p 2222 ps5term@192.168.1.50

File transfer

Any SFTP client works, starting in /data.

sftp -P 2222 ps5term@192.168.1.50

Controls

Keyboard, mouse or controller

Use whichever you have. The hints on screen name the keys of what you used last.

⌨️

Keyboard

Type as usual. Shift+F10 opens the actions menu, Ctrl+Shift+S Settings. In a Linux program every F-key belongs to the program.

🖱️

Mouse

Click any button or on-screen key, drag to select, right-click for the menu and middle-click to paste.

🎮

Controller

Triangle opens the on-screen keyboard, R2 runs, L3 opens actions and Options Settings. Its keyboard has Esc, Tab, Ctrl, arrows and F1–F10.
