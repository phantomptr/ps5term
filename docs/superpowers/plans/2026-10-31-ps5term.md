# PS5Term implementation plan

Goal: deliver a native PS5 terminal folder and ZIP with a bundled real shell backend, targeting firmware 13.60.

Architecture: retain the recommended C++20 VideoOut/runtime/build foundation. Separate bounded terminal state, Telnet transport, platform input, and rendering. Vendor the GPL shell core at a pinned revision; build a dedicated loopback-only backend on port 2324, launched through the already-running ELF loader on 9021. No claims of full POSIX shell or TTY compatibility.

- [ ] Test terminal stream fragmentation, scrollback, ANSI handling, history and input bounds; implement terminal state.
- [ ] Test Telnet negotiation and partial nonblocking transport; implement backend connection and launch.
- [ ] Add native keyboard/controller input and on-screen keyboard, dynamic rendering, and deterministic vector branding.
- [ ] Build pinned shell core and native app in Linux; run host and tooling checks; inspect package metadata, assets, runtime and ELF.
- [ ] Produce folder ZIP, hashes, visual preview and installation guide. Hardware launch on 13.60 remains a separate verification step.
